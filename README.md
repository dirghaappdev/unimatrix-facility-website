## 🚀 How to Open and Run

### Option 1: Direct in Any Browser (No Installation Required)
Simply double-click `index.html` or open it with Chrome, Edge, Safari, or Firefox:
```
C:\Users\DELL\.gemini\antigravity\scratch\unimatrix-facility-website\index.html
```

### Option 2: Run with Local Python Server
Open a terminal in the folder and run:
```bash
python -m http.server 8080
```
Then visit: `http://localhost:8080`

### Option 3: Deploy Online
The code is 100% self-contained static HTML5, Tailwind CSS, and vanilla ES6 JavaScript. You can deploy it instantly to:
- **GitHub Pages**
- **Vercel**
- **Netlify**
- **Hostinger / GoDaddy / cPanel**
